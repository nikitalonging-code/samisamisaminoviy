# v47 — Exact home navigation / GRAM / red-black UI

Изменения сделаны поверх v46 максимально изолированно, чтобы не ломать существующую игровую логику.

- Главный экран использует предоставленные пользователем ассеты: баланс, иконки, Ракетка, CASES, TILT PLAY и ICE ARENA.
- Ракетка открывает существующий Crash/Rocket экран.
- CASES открывает существующий экран кейса.
- TILT PLAY открывает существующий Play Hub.
- ICE ARENA открывает существующий Ice Arena.
- LIVE-лента находится непосредственно под блоком баланса/иконок и продолжает получать данные с `/api/live`.
- Нижняя навигация приведена к 5 кнопкам как на макете: Инвентарь / Реф / Главная / Рейтинг / Задания. Визуально используется предоставленный полупрозрачный ассет `home_bottom_nav.png`, а поверх него оставлены рабочие click-зоны.
- Все визуальные обозначения валюты в интерфейсе используют GRAM и `assets/gram_icon.png`.
- Основная UI-палитра переведена в красно-чёрную без изменения серверных внутренних идентификаторов TON Connect/TON API, чтобы не сломать существующую интеграцию.
- `frontend/index.html` и `frontend/app.html` синхронизированы.
- Backend-сообщения, которые показываются пользователю, переведены с TON на GRAM.
