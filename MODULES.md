# Карта отделов проекта

## FRONTEND
- **Главный экран / навигация** — верхняя панель, LIVE, Play Hub, переходы.
- **Инвентарь** — NFT, продажа, отправка подарков.
- **Приглашения / рефералы** — ссылка, приглашения, начисления.
- **PVP / Ice Arena** — поле, ставки, зоны, таймер, шар, победитель.
- **Рейтинг** — оборот TON и таблица игроков.
- **Награды / задания** — задания и награды.
- **Ракетка / Crash** — раунд, ставки, cashout, LIVE-ставки.
- **Кейсы** — Promo Case, Summer Case, reel, дроп, результат.
- **Upgrade** — выбор NFT, шанс, вращение и результат.
- **TON Connect / Пополнение** — подключение кошелька и депозит.

## BACKEND
- **База данных** — подключения, таблицы, миграции.
- **Telegram / авторизация** — initData, user ID, admin IDs, webhook.
- **Ice Arena / PvP** — пул игроков, ставки, победитель, расчёт.
- **Профиль / баланс / инвентарь** — пользовательские данные.
- **Вывод NFT** — заявки и уведомления админов.
- **Рефералы / активность / LIVE** — события и реферальная логика.
- **Кейсы / промокоды** — открытие Promo Case и админские промокоды.
- **Админ-панель** — TON, NFT, бан, рассылка, пользователи.
- **MRKT** — цены и NFT-данные.
- **TON / депозиты** — intents, статусы и подтверждение входящих транзакций.

## WORKER
- **MRKT Worker** — получение/кэширование MRKT-токена и обслуживание worker API.

## ВАЖНО
Разделение сделано на уровне читаемых секций/модулей и комментариев; поведение приложения намеренно не менялось. Это безопасная организационная версия, чтобы дальше можно было менять только нужный отдел.
