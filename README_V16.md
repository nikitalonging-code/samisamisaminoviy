# NFT Gift v16

Ice Arena теперь использует механику из `ice_arena_modified(2).html` как основу визуала и движения шара.

PvP-логика:
- первый игрок занимает 100% поля своим стабильным цветом;
- второй игрок переразбивает поле пропорционально ставкам (например 1 TON vs 10 TON = 9.1% / 90.9%);
- могут добавляться и следующие игроки;
- после второй ставки запускается 20-секундный таймер сверху;
- после таймера появляется "Шар на поле", затем запускается визуальная последовательность движения шара;
- победитель определяется backend по весу ставки;
- цвет пользователя не меняется при переразбивке поля.

Дополнительно:
- убраны декоративные Lol Pop из PVP/Play Hub, вместо них используются Durov's Cap;
- referral endpoint больше не возвращает bot deep-link, который мог приводить к BOT_INVALID; копируемая ссылка — web-app URL с `?ref=`.
